What Phase 6 set out to do

Changing a line of text on the website used to mean asking somebody technical, waiting, and trusting that nothing else moved. That is the reason marketing sites go stale: the cost of a small change is never the change itself.

Website Studio removes that cost, without giving up the safety that made the old arrangement bearable. Nothing reaches the public that has not been looked at first.

How it works

Edit
In the Hub, on the page itself
Pick a page, click the part of it you want to change, and edit the words, pictures or menus. A live preview beside the editor shows the real page, not an approximation. Text can be styled as it will appear.
Review
On a private copy of the site
Publishing puts the change on a full copy of the website that the public cannot find and search engines ignore. The live site is untouched at this point.
Go live
Once, deliberately
Only a version that has been through review can be published to the real site, so there is one road to the public and a check on it.
Go back
If it was not right
Any of the last five published versions can be restored, and the editor returns to that version with it, so the change is not left waiting to be published again.

Built so a mistake is not permanent

  • ✓The last five published versions are kept in full, not as a list of changes but as complete copies of the site, so going back is immediate rather than a reconstruction.
  • ✓Going back takes the editor with it, so the change that was undone does not sit waiting to be published again by accident.
  • ✓An edit can be put back to what the site says one band at a time, without touching the rest of the page.
  • ✓Publishing is a marker in time. What was published becomes the point everything is measured from, and the point going back returns to.
  • ✓The live site keeps its own history, so even a change that reached the public can be reversed.

The details that are easy to get wrong

Search wording. The titles and descriptions search engines show are written by hand and do not always follow the words on the page. Rather than rewrite them silently or leave the mismatch hidden, the Studio reports what it could not carry across, so stale wording is visible instead of discovered months later.

Pictures. Images are sent straight from the browser to storage rather than through the application, which is what makes the stated size limit real rather than theoretical. Each upload is checked on arrival, and a file that is not the kind of image it claims to be is rejected and removed.

Formatting. Bold, lists, sizes and links are written back in exactly the form the existing website uses, so an edited section is indistinguishable from one that was never touched.

Where the project stands

This is the last of the six phases. ABG now owns and controls the application, the database, the files, the website, the domain and the process that deploys all of it. Nothing depends on a single machine, a single person, or an outside supplier.

One item remains open and is waiting on AWS rather than on work: the delivery network in front of the website still runs in a supplier account until ABG's own account is cleared for that service. The procedure for moving it is written down and handed over.
